# AGIChat SDK

SDK de widget de chat agéntico, embebible en el producto de cualquier cliente.

La Fase 1 entrega la interfaz completa conectada a un servidor mock que simula
un agente con streaming token por token. La Fase 2 sustituye ese mock por el
agente real sin rediseñar la interfaz.

## Estado

En construcción. La documentación de arquitectura vive en `docs/ARQUITECTURA.md`
y las convenciones para herramientas de codeo agéntico en `AGENTS.md`.
